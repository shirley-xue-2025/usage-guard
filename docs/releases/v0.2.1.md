# v0.2.1 — 2026-06-25

Includes everything in [v0.2.0](v0.2.0.md), plus:

## `weekly_pause_within_hours`

Weekly PAUSE at 98% only when the weekly reset is **within N hours** (e.g. `5`). If weekly is high but reset is days away, you stay `RUN` — the 5-hour guard still applies independently.

```json
{
  "weekly_enabled": true,
  "weekly_threshold_pause": 98,
  "weekly_pause_within_hours": 5
}
```

Omit `weekly_pause_within_hours` (or `null`) for v0.2.0 behavior: pause at 98% regardless of reset time.
