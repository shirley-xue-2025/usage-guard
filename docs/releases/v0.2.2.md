# v0.2.2 — fail closed + supervised daemon

## Highlights

- **`state: UNKNOWN` when blind** — after 3 null usage polls, the guard no longer advertises `RUN`
- **`valid_until` freshness contract** — consumers treat past-`valid_until` as `UNKNOWN` (covers "daemon died while numbers looked healthy")
- **LaunchAgent KeepAlive** — `install.sh` installs `io.usage-guard.daemon`; crashes restart, clean disarm stays down
- **Blind alert backoff** — re-notify hourly, then daily, instead of one vanishing banner

## Upgrade

```bash
cd usage-guard
git pull
./install.sh
usage-guard doctor
usage-guard status   # look for valid_until / launchd line
```

Re-arm after install if you want the supervised daemon path immediately.
